# แหล่งข้อมูล

## ThaiWater (สสน.) — แหล่งหลัก

Base: `https://api-v3.thaiwater.net/api/v1/thaiwater30/public` ไม่ต้องใช้ key แต่ไม่ใช่ API ทางการ

| endpoint | ใช้ทำอะไร | รูปแบบข้อมูล |
|---|---|---|
| `waterlevel_load` | ค่าล่าสุดราว 800 สถานี | `waterlevel_data.data[]` แต่ละแถวมี `station.id`, `waterlevel_datetime`, `waterlevel_msl`, `discharge` |
| `waterlevel_graph?station_type=tele_waterlevel&station_id=&start_date=YYYY-MM-DD&end_date=YYYY-MM-DD HH:MM` | ย้อนหลังสูงสุด ~365 วัน | `data.graph_data[]` มี `datetime`, `value`, `discharge` บางสถานีตอบ 500 |
| `rain_24h` | ฝน 24 ชม. ราว 4,400 สถานี | ยังไม่ได้ใช้ |

ข้อควรระวัง
- ตั้งแต่ปลาย ก.ย. 2569 เคยตอบ 429 ให้ poll ทุก 10 นาที ส่ง User-Agent แบบเบราว์เซอร์ และ Referer `https://www.thaiwater.net/`
- ค่า sentinel เช่น 999999 ต้องตัดทิ้ง (`thaiwater._float`)

## เกณฑ์ระดับน้ำ P.1 (ตามไม้วัด)

ระบบตั้งไว้ที่ เฝ้าระวัง 3.10 / วิกฤต 3.70 / ล้นตลิ่ง 4.20 ม. ตาม MaeNam Flow และประกาศกรมชลฯ ปี 2567
แต่ appserv.net แสดง "จุดวิกฤติ" ของ P.1 เป็น 4.20 ม. (ปริมาณน้ำ 416 m³/s) เกณฑ์อาจถูกปรับหลังปี 2567
ค่าจึงอยู่ใน env (`P1_WATCH_M`, `P1_CRITICAL_M`, `P1_OVERFLOW_M`) ต้องยืนยันกับกรมชลฯ ก่อนเปิดให้ใช้งานจริง

## แหล่งสำรองและอ้างอิง

- **appserv.net/pingriver.php, /cm-table.php:** โทรมาตรกรมชลฯ รายชั่วโมง 72 ชม. ของ P.1, P.67, P.75, P.92, P.20 (ระดับตามไม้วัด) และปริมาณน้ำของ P.1/P.67 มีภาพ CCTV ที่ P.1 ด้วย ค่าตรงกับ ThaiWater ทุกชั่วโมงในช่วงที่ซ้อนกัน (1 ต.ค. 2569) เมื่อแปลง P.67 ด้วยศูนย์ไม้วัด 315.93 ม.รทก.
- **github.com/xuantinhsea/thai-hydro-watch:** snapshot ของ ThaiWater (`data/dataset.js`) ระดับน้ำและปริมาณน้ำรายชั่วโมงตั้งแต่ 1 ก.ย. 2569 ของหลายร้อยสถานี รวม P.1/P.67/P.21 เป็นที่มาของ `data/backtest/thaiwater_2026_sep.csv` (snapshot เมื่อ 3 ต.ค. 2569 22:17 น.) ใช้เป็นแหล่งข้อมูลทดสอบเท่านั้น
- **maenamflow.com:** โปรเจกต์อิสระ แสดง P.1 พร้อม MSL และฝนจาก Open-Meteo ใช้ตรวจ datum ได้
- **hydro-1.rid.go.th:** ข้อมูลรายชั่วโมงรายเดือน (`water_today_search.php?storage=P.1&yy=&mm=`) แต่ robots ไม่อนุญาตให้ดึงอัตโนมัติ ให้ทำหนังสือขอข้อมูลแทน
- **Open-Meteo:** พยากรณ์ฝนรายชั่วโมงและ Flood API (GloFAS) ฟรี ไม่ต้องใช้ key

## พฤติกรรมข้อมูลที่รู้แล้ว

- กรมชลฯ ป้อนข้อมูลช้า 1–2 ชม. หน้าเว็บต้นทางแสดง "รอเจ้าหน้าที่ป้อนข้อมูล"
- ช่วง 23:00–00:00 มักหาย (ในข้อมูลปี 2567 หาย 35/432 ชม.) ระบบเติมได้ไม่เกิน 3 ชม.
- appserv ใช้ "24:00" แทน 00:00 ของวันถัดไป
- **ระดับน้ำ P.1 อาจขึ้นหรือลง 20–45 ซม. ภายในไม่กี่ชั่วโมงโดยปริมาณน้ำแทบไม่เปลี่ยน** พบ 6 ครั้งใน ก.ย. – 4 ต.ค. 2569 (รายการอยู่ใน experiment-findings) น่าจะเกิดจากการบริหารประตูระบายน้ำท้ายน้ำ ยังไม่ยืนยันกับกรมชลฯ ระบบตรวจจับด้วย `forecast_logic.level_controlled`
- **ปริมาณน้ำ (`discharge`) ของ P.1 มีให้ทั้งใน `waterlevel_load` และ `waterlevel_graph`** ระบบเก็บไว้ในคอลัมน์ `obs.discharge` และ `store.hourly()` คืนเป็นคอลัมน์ `Q1` แต่ข้อมูล seed ปี 2567 ไม่มีค่านี้
- **ThaiWater ส่งค่าผิดพลาดมาได้** เช่น P.21 = 493.70 ม.รทก. เมื่อ 4 ก.ค. 2569 13:00 (ตลิ่ง 323.50) ระบบตัดค่าที่อยู่นอกช่วงตลิ่ง −10 ถึง +8 ม. (`config.plausible`) ทั้งตอนรับข้อมูลและตอนอ่าน
